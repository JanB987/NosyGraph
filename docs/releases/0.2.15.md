## NosyGraph 0.2.15

This patch keeps graph root links synchronized after note renames and makes
nodes in the active Lens stay in front of other overlapping lenses.

### Rename and move fixes

- Update links in explicitly configured root-node properties and plugin-level
  default root properties for open graph notes and loaded graph-note lenses.
- Handle short and relative links in the source note's context while preserving
  wiki aliases, heading fragments, Markdown labels, and scalar/list values.
- Preserve links to different existing notes with the same basename.
- Use atomic vault operations for root-property and graph-state changes so
  saves preserve concurrent automatic link updates and note-body edits.
- Skip unchanged graph-state saves to avoid unnecessary modify events.

### Lens foreground fixes

- Bring the most recently opened or used Lens to the foreground when clicking,
  moving, resizing, or zooming it.
- Use the same stacking order for frames, node and label painting, coverage,
  and mouse targets. A background Lens no longer fades or hides active nodes
  or intercepts clicks through the foreground Lens.
- Keep nested lenses above their parents and preserve focus during background
  definition refreshes and same-graph reloads.

### Validation and compatibility

- 596 tests across 106 files pass, including rename, concurrent-save,
  overlapping-Lens, canvas draw-order, and pointer-target regressions.
- Scoped typecheck, full lint (including the Obsidian settings-heading rule),
  production build, bundle syntax, metadata, and whitespace checks pass.
- Minimum Obsidian version remains **1.5.0**. Existing settings are preserved.
- Native Obsidian smoke testing and the external Obsidian dashboard scan remain
  maintainer checks; the automated tests do not establish the dashboard result.

### Update

Use Obsidian's community plugin updater, or replace `main.js`,
`manifest.json`, and `styles.css` in `.obsidian/plugins/nosygraph/`.
Keep your existing `data.json`, then reload NosyGraph.
