## NosyGraph 0.2.12

This patch publishes the plugin-checker fixes under a new version so Obsidian
can run a fresh release scan. Runtime code matches the corrected 0.2.11 build.

### Included fixes

- Preserve Obsidian 1.5.0 compatibility: guard newer vault-storage APIs, provide
  a vault-scoped fallback with migration, and parse property IDs without the
  newer Bases helper.
- Use preferred Obsidian DOM helpers and an Obsidian confirmation modal for
  Templater batches.
- Correct paste-event, promise, type, and unload handling; remove deprecated
  slider tooltip calls and restore the extracted engine's typed preview module.

All 0.2.11 features and fixes are included: persistent grouping and Lens state,
multiple connected Base views, corrected Base filters, and case-insensitive
LinkType property matching.

### Validation and installation

The corrected runtime passed 551 tests across 103 files. Local checks for the
reported lint rules passed with zero errors or warnings. This release reruns
those lint checks, the scoped typecheck, and the production build, and verifies
version consistency. The external Obsidian scan still needs to run.

Minimum Obsidian version: **1.5.0**. NosyGraph remains beta; manual large-vault,
nested-Lens, Templater, and clean-install validation remain outstanding. The
experimental replacement runtime and separate 0.3 plugin remain excluded.

Install the attached `main.js`, `manifest.json`, and `styles.css` in
`.obsidian/plugins/nosygraph/`, preserve `data.json`, and reload NosyGraph.
