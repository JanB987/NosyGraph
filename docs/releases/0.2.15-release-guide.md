# NosyGraph 0.2.15 release verification

Repository: https://github.com/JanB987/NosyGraph

## Scope

This patch includes the rename/move and Lens foreground fixes described in
[the release notes](0.2.15.md). The active development and installed runtime
folder is `.obsidian/plugins/nosygraph`.

## Release process

1. Synchronize and review `main`; keep published release tags immutable.
2. Set manifest, package, and both lockfile root versions to 0.2.15, and map
   0.2.15 to minimum Obsidian 1.5.0 in `versions.json`.
3. Run `npm run build`, `npm test`, `npm run typecheck`, `npm run lint`, bundle
   syntax checking, version consistency checks, and `git diff --check`.
   Expected baseline: 596 tests in 106 files.
4. Commit the reviewed files on `main`, create annotated tag `0.2.15` at that
   commit, and push both without rewriting existing refs.
5. Create a draft GitHub release with `0.2.15.md` as its description. Upload
   `main.js`, `manifest.json`, and `styles.css`; verify upload SHA256 digests.
6. Publish as the latest normal release. Verify main and the annotated tag,
   inspect the corrected source on both refs, and download the public assets.
   Their hashes must match the staged build and installed runtime.

Assets, checksums, verified downloads, and the release receipt are staged in
`.obsidian/release-staging/NosyGraph-0.2.15`, outside the repository.
Never publish vault settings or `data.json` with the assets.

## Maintainer checks

- Reload NosyGraph and confirm version 0.2.15.
- With a graph and Lens open, rename and move a note linked from a property in
  `rootNodeProperties`. Repeat with default root properties, short wiki links,
  relative Markdown links, aliases, and heading fragments.
- Confirm both the links and rendered graph update while preserving saved
  positions, pins, expanded badges, and unrelated note-body edits.
- Overlap two lenses. Click or move the exposed title bar of the rear Lens;
  its nodes should become fully visible and receive clicks in the overlap.
- Repeat with viewport zoom, resizing, and nested lenses. A child Lens stays
  above its parent. Background metadata refreshes retain foreground order.
- Update a copied vault using the three assets while preserving `data.json`.
- Run the external Obsidian precheck/scan against 0.2.15 and inspect its result.
  Do not mark the dashboard scan as passed based only on local lint.
