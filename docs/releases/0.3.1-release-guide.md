# NosyGraph 0.3.1 release verification

The 0.3.1 candidate addresses the one error and fifteen warnings reproduced locally against 0.3.0 using ESLint and `eslint-plugin-obsidianmd` 0.4.2. Production lint now enforces all seven affected rules as errors. See the [release notes](0.3.1.md) and [changelog](../../CHANGELOG.md).

## Release checks

- Run the full test suite, architecture typecheck, production lint and production build. Check bundle syntax and scan production source and the bundle for regex lookbehind.
- Compare full-project TypeScript diagnostics with the 0.3.0 baseline. The baseline has 115 diagnostics.
- Verify 0.3.1 in the manifest, package metadata, both package-lock version fields and the versions map. Minimum Obsidian is 1.5.0 and mobile remains supported.
- Compare the development and release checkout artifacts and verify Git whitespace before preparing the release.

Implementation validation passed 89 focused compatibility tests across 8 files and 26 focused Graph Tab tests across 3 files. Fresh release validation passed 755 full-suite tests across 120 files, architecture typecheck, production lint, build, syntax, the lookbehind scan, metadata and Git whitespace checks. Full-project TypeScript reported the same 115 diagnostics after accounting for shifted source lines.

The published production bundle must match the accepted development and installed bundles. Verify main and the annotated 0.3.1 tag point to the same release commit; download all three public assets and compare their SHA-256 hashes with the staged files. Release receipts, checksums and compiler logs are kept under `.release-work/0.3.1`, outside the tracked repository. Do not upload vault settings, credentials, logs or backups.

## Manual Obsidian checks

- Reload the vault and confirm NosyGraph 0.3.1 starts. Check startup and clipboard paste on older iOS if a device is available.
- Paste a mix of wiki links, Markdown links, prose and external URLs in a badge input. Verify previews and skipped URLs.
- Cut from a graph, nested Lens and property expansion, then paste. Verify source-property edits and partial-failure handling.
- Switch Graph and Markdown modes, navigate selected notes, and link, unlink and reopen a follower. Verify editing and source isolation. Click node A, then B, then A again in the source graph. The follower should update while keyboard focus stays in the source graph.
- Change selections rapidly in a popout and close the graph or embed. Check for stale updates or console errors.
- Create a graph note using a template with a Unicode filename and spaces.
