## NosyGraph 0.2.14

This patch fixes the settings heading flagged by Obsidian's automatic checker
preview for 0.2.13. It includes all 0.2.13 graph-refresh and settings improvements.

### Fixed

- Remove the redundant NosyGraph heading from the plugin settings panel.
  The introduction remains as descriptive text, and all controls are preserved.
- Adjust the introduction spacing to match the updated layout.
- Enable the exact Obsidian settings-heading lint rule so this error is caught
  during local validation before future releases.

### Validation and compatibility

- The exact checker rule reproduces the original error and passes on the fix.
- 560 tests across 104 files, the scoped typecheck, production build, full lint,
  version checks, and Git whitespace checks pass.
- Local browser previews confirm the introduction and all 70 settings controls
  remain available, with no narrow-layout overflow.
- Minimum Obsidian version remains **1.5.0**. Existing settings are preserved.
- The external Obsidian precheck/scan must be rerun against **0.2.14**; the
  published 0.2.13 tag and assets remain unchanged.

### Update

Use Obsidian's community plugin updater, or replace `main.js`,
`manifest.json`, and `styles.css` in `.obsidian/plugins/nosygraph/`.
Keep `data.json`, then reload NosyGraph.
