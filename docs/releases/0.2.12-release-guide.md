# Verify NosyGraph 0.2.12

Repository: https://github.com/JanB987/NosyGraph

This is a new patch release of the corrected 0.2.11 runtime. Obsidian rejected
another release scan for 0.2.11 because that version had already been scanned.
Keep published tags intact for future fixes; publish a new patch version.

## Release validation

1. Confirm `manifest.json`, `package.json`, and both root entries in
   `package-lock.json` use 0.2.12; `versions.json` maps it to 1.5.0.
2. Run the reported-rule lint checks, `npm.cmd run typecheck`, and
   `npm.cmd run build`. The unchanged runtime already passed 551 tests in 103 files.
3. Commit on `main`, create annotated tag `0.2.12` at that commit, and push both.
4. Publish https://github.com/JanB987/NosyGraph/releases/tag/0.2.12 with
   `main.js`, `manifest.json`, and `styles.css`, using `0.2.12.md` as the notes.
5. Download the public assets and compare their SHA256 hashes to the staged files.

Staging and release receipt: `.obsidian/release-staging/NosyGraph-0.2.12`
in the vault, outside the source repository.

## Maintainer checks

1. In the Obsidian developer dashboard, open NosyGraph and select
   **Check for new releases**, then review the new 0.2.12 scan results.
2. Reload the locally installed plugin and confirm version 0.2.12.
3. Exercise grouping and Lens close/reopen persistence, multiple connected
   Bases and filter results, relationship property casing, and Templater
   batch confirmation if Templater is installed.
4. For a clean-install check, install the three release assets in a test vault.
   Preserve `data.json` when updating an existing installation.

Do not claim the external checker passed until its dashboard reports the result.
