## NosyGraph 0.3.1

This patch fixes the compatibility findings reported by Obsidian's automatic checker after 0.3.0. It also fixes a Graph Tab focus issue that interrupted selection in the source graph.

### Older WebKit compatibility

The clipboard parser no longer uses regex lookbehind, which is unsupported on iOS versions before 16.4 and could prevent the plugin from loading. Pasted links and skipped external URLs keep their original text and offsets, including in quoted property lists. Link recovery and escaped punctuation handling are preserved.

### Graph Tabs keep focus in the source graph

A Graph Tab can now follow selected notes without taking keyboard focus from the graph you are working in. This also applies when returning to a note already viewed in the follower. The follower restores the note's cursor and scroll position without using the native cursor restoration path that could focus its editor.

### Checker fixes and regression checks

- Use browser-window timers for Graph Tab selection updates, with matching cancellation during cleanup.
- Bind workspace navigation callbacks explicitly and preserve their original hooks when the controller is disposed.
- Keep the Cut write barrier concurrent, with explicit Promise entries and the same failure behavior.
- Use window-scoped crypto for Graph Tab session IDs.
- Preserve template-path control-character rejection without a control-character regex, and remove unnecessary bracket escapes.
- Enforce all seven rules behind the original checker findings in local production lint.

### Included features

This patch includes all 0.3.0 features: editable Graph Tabs with a resizable selected-note list, linking to a specific source tab, Cut across graphs and lenses, clipboard batches in badge inputs, the graph-membership toggle, configurable LinkType badge icons, and optional graph-note templates. See the [0.3.0 release notes](https://github.com/JanB987/NosyGraph/releases/tag/0.3.0) for the full feature descriptions.

### Verification and update

- 755 tests across 120 files pass, along with the architecture typecheck, production lint, build, bundle syntax, lookbehind scan, metadata and whitespace checks.
- Full-project TypeScript retains the same 115 legacy diagnostics; this is not a clean full-project typecheck.
- Minimum Obsidian remains **1.5.0**, and mobile support remains enabled. Local checks do not replace older-iOS testing or the external Obsidian checker; the external scan must run against this new release.

Update through Obsidian's community plugin updater, or replace `main.js`, `manifest.json`, and `styles.css` in `.obsidian/plugins/nosygraph/`. Preserve `data.json`, then reload NosyGraph. This remains a beta release; keep your usual vault backups.
