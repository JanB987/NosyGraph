## NosyGraph in general

NosyGraph is an Obsidian plugin for a markdown/frontmatter-driven working
memory graph. The public plugin name is **NosyGraph**, the Obsidian plugin ID is
`nosygraph`, and the active local folder is still named
`Bases - Graph-View - V2` for continuity with the earlier plugin.

The graph derives relationships from configurable frontmatter/YAML link
properties and link-type notes. It supports root nodes, link-type badge
expansion and collapse, lenses and embedded/nested graph contexts, graph-note
JSON persistence in `o3graph` blocks, pinned positions, drag and drop, and
frontmatter-driven refreshes. Badge interactions can add or remove visible
branches; in a graph note, the committed visible topology must be written back
to the graph note so a close/reopen restores the same state.

The plugin is local and host-bound to Obsidian. It does not depend on a remote
service at runtime. The current release is beta-quality: automated coverage is
strong for the extracted architecture, while several interactive and large
vault scenarios still require evidence in Obsidian.

## Runtime architecture truth

The live production composition is still:

```text
GraphView -> GraphEngine
```

`GraphEngine` remains the live owner of graph collections, supported
interaction state, the animation loop, legacy physics, lenses/containers, and
legacy persistence paths.

The replacement composition is implemented and tested but experimental:

```text
StoreGraphRuntime
  -> GraphStore
  -> GraphController
  -> GraphRenderer
  -> replaceable physics
  -> persistence/lifecycle ports
```

Store mode is guarded and is not the production default. Do not remove legacy
arrays, executors, solver paths, or shadow services until the activation gates
and ownership audit are cleared.
